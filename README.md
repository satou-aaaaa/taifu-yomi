# 台風よみ（taifu-yomi）

台風の最大風速と強風域の半径を見て、強さの呼び方（強い・非常に強い・猛烈な）を当てる1日5問の学習ゲーム。正解したら大きさの呼び方（大型・超大型）も選ぶ。暴風域・予報円・上陸・接近などのことばや、台風の数（平年値）の問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/taifu-yomi/>

- 中身は気象庁の台風のページ（「台風の大きさと強さ」<https://www.jma.go.jp/jma/kishou/know/typhoon/1-3.html>・「台風とは」・「台風の番号の付け方と命名の方法」・「予報用語 台風」・「台風に伴う風の特性」・「台風の平年値」）に書いてあることだけです。
- 問題に出る台風の数は練習のための例で、本物の台風ではありません。
- このゲームは防災の助言や、公式の情報の代わりではありません。台風の情報は気象庁で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
